# Vehicle Pre-Booking System

## Project Description

The Vehicle Pre-Booking System is a DBMS-based project developed using SQL to manage vehicle reservations efficiently. It stores vehicle details, customer information, and booking records in a relational database.

## Features

* Manage vehicle details
* Store customer information
* Book vehicles for specific dates and times
* View booking records
* Update booking details
* Delete booking records
* Prevent duplicate bookings for the same vehicle, date, and time

## Technologies Used

* Database Management System (DBMS)
* SQL
* Relational Database Concepts

## Objective

The main objective of this project is to simplify vehicle reservation management and maintain booking information accurately using database operations.
